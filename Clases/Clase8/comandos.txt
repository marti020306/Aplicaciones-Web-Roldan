comandos de consola


Comandos primera vez (en su casa)

    -INSTALAR NODE JS
    -verificar instalacion 
    node -v
    npm -v

    -Instalar manejador de paquetes pnpm
    npm i -g pnpm
    pnpm -v

    Por proyecto:

    -Verificar si no existe el package.json
    pn init

    -Instalar paquete five server
    pn add five-server

    -Reinstalar paquetes si existe package .json
    pn install

    -Configurar scripts -> "dev":"five-server  "
